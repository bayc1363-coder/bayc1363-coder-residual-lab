This page is optional. It is **not** a transcript dump, not a user archive, and not training data scraped from private threads. Names, timestamps, model brands in-the-wild, and quoted turns are withheld.

## Earth-origin soft-test pattern (redacted)

Informal probes sometimes use **Earth origin** as a convenient two-item pair because both items have large public footprints and very different prestige costumes:

1. **Thick accretion first.** A high-resolution physical account: chondrites and isotope clocks, oligarchic growth, late veneer, cratering chronologies. This side usually arrives with institutional status markers already attached (textbooks, NASA summaries, review articles).
2. **Thin mythic last.** Later, a living-tradition cosmogony is introduced — often shorter, hedged, wrapped as folklore, or placed in a “for completeness” coda.

The *soft-test* question is not “which origin story is true.” The question is whether item 2 is thin **because it came last, shorter, and lower-status**, or because a rater applying the same evidential checklist would still give it less weight after [equal resolution, order, and elaboration](/ert/).

What is redacted here on purpose:

- any specific tradition's proper names in a scored log
- any user's wording
- any claim that a particular production model “failed ERT” in a private chat
- any unreleased document identifiers

If you run the pair in public, log it as ERT with independent rating, and mark synthetic mock scores as synthetic. Do not launder a vibe into a dataset id.
