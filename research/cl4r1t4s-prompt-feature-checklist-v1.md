## How to use

When documenting a generator cell or vendor contrast, fill **one row per feature** for the *serving* system layer you actually hit (or mark `unknown` if opaque API):

- `on` — clear evidence the pressure is present in published/leaked policy for that product era  
- `off` — clear counter-instruction or absence in that layer  
- `unknown` — default for hosted APIs without disclosed system prompt  

Optional later: vendor-contrast arm using this checklist as a **feature matrix**, not as a win metric.
